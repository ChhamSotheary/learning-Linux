# ចម្លើយណែនាំ៖ មេរៀនទី ៧

## ផ្នែក A

1. IP កំណត់អាសយដ្ឋាន host/interface; gateway បញ្ជូន traffic ទៅ network ផ្សេង; DNS បកប្រែ hostnames ទៅ addresses។
2. TCP ផ្ដល់ reliable ordered stream; UDP ផ្ញើ datagrams ដោយមិនធានា delivery/order នៅ transport layer។
3. ss -tuln រាយ TCP/UDP listening sockets និងបង្ហាញលេខ address/port ដោយមិន resolve names។
4. ICMP អាចត្រូវបាន filter ឬ disable ទោះ service ផ្សេងនៅដំណើរការ។
5. ទេ។ Firewall, routing, bind address និង network perimeter កំណត់ថាអាចចូលពីកន្លែងណា។

## ផ្នែក B

លទ្ធផលខុសគ្នាតាមម៉ាស៊ីន/network។ យក output ពិតពីម៉ាស៊ីនអ្នក។ បើ ip command ឬ permission មិនអាចបង្ហាញព័ត៌មាន សូមកត់ត្រា error ដោយមិនបិទ security controls។
