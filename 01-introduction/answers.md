# ចម្លើយណែនាំ៖ មេរៀនទី ១

ចម្លើយខាងក្រោមជាគំរូ។ អ្នកអាចប្រើពាក្យផ្ទាល់ខ្លួនបាន។

## ផ្នែក A
1. Kernel គ្រប់គ្រង Hardware និងធនធានដូចជា CPU, RAM និងឧបករណ៍ Input/Output។
2. Distribution គឺជាប្រព័ន្ធដែលរួមមាន Linux Kernel, System Tools និងកម្មវិធីចាំបាច់។ ឧទាហរណ៍ Ubuntu, Debian និង Fedora។
3. Terminal ជាផ្ទាំងសម្រាប់បញ្ចូល និងបង្ហាញអត្ថបទ។ Shell ជាកម្មវិធីដែលបកស្រាយ និងដំណើរការ Command។
4. Open Source មានន័យថា Source Code អាចត្រូវបានសិក្សា និងកែប្រែតាមលក្ខខណ្ឌ License។
5. Manual ជួយឱ្យយល់ Syntax, Options និងផលប៉ះពាល់របស់ Command។

## ផ្នែក B
លទ្ធផលអាស្រ័យលើកុំព្យូទ័ររបស់អ្នក៖
- `whoami`៖ Username បច្ចុប្បន្ន។
- `pwd`៖ ទីតាំង Folder បច្ចុប្បន្ន។
- `date`៖ ថ្ងៃ និងម៉ោងប្រព័ន្ធ។
- `uname -r`៖ កំណែ Linux Kernel។
- `cat /etc/os-release`៖ ឈ្មោះ និង Version របស់ Distribution។

## ផ្នែក C
1. Linux មានស្ថិរភាព អាចកំណត់រចនាសម្ព័ន្ធបានច្រើន និងមានឧបករណ៍គ្រប់គ្រង Server។
2. ចម្លើយអាស្រ័យលើ Distribution ដែលអ្នកបានដំឡើង។
3. ប្រើ `man command`, `command --help` ឬឯកសារផ្លូវការរបស់ Distribution។

**ចំណាំ៖** ផ្នែកអនុវត្តត្រូវយកលទ្ធផលពិតពីម៉ាស៊ីនរបស់អ្នក។
