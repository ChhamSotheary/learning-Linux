# លំហាត់មេរៀនទី ១៖ សេចក្ដីផ្ដើមអំពី Linux

សូមសាកល្បងឆ្លើយដោយខ្លួនឯង មុនពិនិត្យចម្លើយ។

## ផ្នែក A៖ សំណួរយល់ដឹង
1. តើ Linux Kernel មានតួនាទីអ្វី?
2. តើ Linux Distribution ជាអ្វី? សូមលើកឧទាហរណ៍ ៣។
3. តើ Terminal និង Shell ខុសគ្នាដូចម្ដេច?
4. តើ Open Source មានន័យដូចម្ដេច?
5. ហេតុអ្វីគួរអាន Manual មុនប្រើ Command ដែលមិនស្គាល់?

## ផ្នែក B៖ អនុវត្ត Command
សូមរត់ Command ខាងក្រោម ហើយកត់ត្រាលទ្ធផល៖

```bash
whoami
pwd
date
uname -r
cat /etc/os-release
```

## ផ្នែក C៖ ពិចារណា
1. ហេតុអ្វី Linux ត្រូវបានប្រើប្រាស់ច្រើនលើ Server?
2. តើអ្នកកំពុងប្រើ Distribution មួយណា?
3. តើអ្នកអាចរកជំនួយសម្រាប់ Command មួយដោយរបៀបណា?

## លក្ខខណ្ឌបញ្ចប់
- អាចពន្យល់ Kernel, Shell និង Distribution បាន។
- អាចរត់ Command ទាំង ៥ ខាងលើបាន។
- អាចបើក Manual និងចេញពី Manual បាន។
