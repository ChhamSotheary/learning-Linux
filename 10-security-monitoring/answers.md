# ចម្លើយណែនាំ៖ មេរៀនទី ១០

## ផ្នែក A

1. Least privilege គឺផ្ដល់សិទ្ធិតិចបំផុតដែលចាំបាច់ដើម្បីធ្វើការងារ។
2. Firewall, bind address, routing និង network perimeter អាចរារាំង ឬកំណត់ access។
3. លាក់ passwords, tokens, private keys, user identifiers និង personal/sensitive details តាមតម្រូវការ។
4. Backup អាចមិនពេញលេញ ឬខូច; restore test បញ្ជាក់ថាវាអាចប្រើស្ដារបាន។
5. ទេ។ ត្រូវប្រៀបធៀបជាមួយ workload, baseline និងរយៈពេល ដើម្បីយល់ថា metric មានន័យអ្វី។

## ផ្នែក B

ចម្លើយអាស្រ័យលើប្រព័ន្ធ។ Report ល្អបំបែក fact ដែលបានឃើញពីការសន្និដ្ឋាន ហើយលាក់ព័ត៌មានរសើប។ បើគ្មាន permission មើល journal ឬ services កត់ថា access ត្រូវបានកំណត់ ហើយស្នើអ្នកគ្រប់គ្រងពិនិត្យតាមផ្លូវការដែលបានអនុញ្ញាត។
