# ចម្លើយណែនាំ៖ មេរៀនទី ៩

## ផ្នែក A

1. Disk ជាឧបករណ៍ផ្ទុក; partition ជាផ្នែក logical; filesystem រៀបចំ files; mount point ជាទីតាំងក្នុង directory tree ដែល filesystem ភ្ជាប់។
2. df បង្ហាញ usage របស់ mounted filesystems។ du បូកទំហំ files/directories ដែលបានជ្រើស។
3. Archive មិនទុកចិត្តអាចមាន paths មិនរំពឹង ឬ files ដែល overwrite ទិន្នន័យ។ ពិនិត្យ contents មុន។
4. Backup អាចខូច ឬមិនគ្រប់គ្រាន់។ Restore test បញ្ជាក់ថាអាចយកទិន្នន័យមកប្រើបាន។
5. Commands ទាំងនេះអាចសរសេរ/format block device និងបំផ្លាញទិន្នន័យដែលមានស្រាប់។

## ផ្នែក B

Output ឧបករណ៍ និងទំហំអាស្រ័យលើម៉ាស៊ីន។ Archive ដែលបាន restore គួរមាន test.txt និងអត្ថបទ Test data។ ប្រសិនបើមិនមាន សូមពិនិត្យ archive listing និង destination path។
