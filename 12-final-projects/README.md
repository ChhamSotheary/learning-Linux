## Portfolio Presentation

សម្រាប់ project នីមួយៗ សរសេរ៖

- Problem និង scope។
- Environment/distribution និង assumptions។
- Commands/configurations ដែលបានប្រើ។
- Security boundaries និង permissions។
- Evidence ពី tests/verification។
- Errors និងរបៀប troubleshoot។
- Backup/recovery/rollback plan។
- ចំណុចដែលត្រូវកែលម្អបន្ទាប់។

លុប secrets, tokens, private IPs, usernames និង personal data ពី screenshots/logs មុនបង្ហោះជាសាធារណៈ។
